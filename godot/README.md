# Luminati — Godot 4 port

The Godot 4.7 version of Luminati. The full write-up is in
[`docs/GODOT_PORT.md`](../docs/GODOT_PORT.md): the approach, how each engine module maps to Godot,
and the phased plan.

## Run

1. Open Godot 4.7 → *Import* → this folder's `project.godot` → *Edit*.
2. Press **F5**. Emberfall loads; Page Up / Page Down switch between the six baked levels.

Controls: WASD / arrows to move, Shift to run, Space / Enter / F to talk and interact, Q / E to
turn, Z / X or the wheel to zoom, T to change the time, R to change the weather, P for photo mode.

## Layout

| Path | Contents |
| --- | --- |
| `levels/<id>/` | baked levels: `world.json` (manifest and gameplay data) and `world.bin.gz` (geometry) |
| `assets/baked/` | baked textures and character sheets |
| `assets/fonts/` | Jersey 15 / 10 and Tiny5 (SIL OFL) |
| `shaders/` | the Luminati materials, sky and colour grade |
| `scripts/luminati/` | engine side: level loading, materials, tile map, lighting, camera, sprites |
| `scripts/game/` | game side: game loop, player, villagers, dialogue |
| `scripts/ui/` | HUD and dialog box |
| `tests/` | the walking-rules parity test and the light-unit calibration |

## Re-bake

The levels are generated by the original JavaScript engine. After changing a level or a generator,
run this from the repository root:

```bash
npm install
node tools/godot-bake/bake.mjs            # all levels; or name one: emberfall
```

Set `CHROME_PATH` if Chrome is not found automatically.

## Test

```bash
godot --headless --path godot res://tests/tilemap_parity.tscn -- --level=emberfall
```
