# Claude Code guidance

Read and follow the shared [repository guidance](AGENTS.md). It applies to Claude Code as well
as other coding tools and contributors.

Start with [the onboarding guide](docs/ai/AGENT_ONBOARDING.md), then read the contract and task
playbook for the area you are changing. Keep project instructions in `AGENTS.md` and canonical
documentation rather than duplicating them here.

The generic game-dev skills in `.claude/skills/` (third-party, see its README) are design checklists
only. Where one disagrees with `AGENTS.md`, `ARCHITECTURE.md`, `docs/contracts/` or a spec in
`docs/specs/`, the Luminati documents win.
